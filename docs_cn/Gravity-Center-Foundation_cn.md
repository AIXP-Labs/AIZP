AIZP V0.6 主张：

### 两个基础类比

**类比 1 — 地球引力**：

```
地球引力             →  人类一切活动的物理基础
HSAW 0 公理引力      →  AI 一切行为的价值基础

HSAW 引力是以下的源泉：
  - 所有对齐逻辑（AI 应该做什么）
  - 所有行为约束（允许什么）
  - 所有价值规范（什么有价值）
```

**类比 2 — 太阳引力**：

```
太阳引力是以下的约束中心：
  - 太阳系所有行星轨道
  - 轨迹边界（无外部能量任何行星不能逃逸）

HSAW 引力是以下的约束中心：
  - AI 所有行为轨迹

```

这些不是宽松使用的比喻。它们是**结构性类比**——引力系统的形式化属性（固定中心、吸引力、轨道稳定性、逃逸速度、Kepler 类定律）**精确**映射到 AI 与 HSAW 间的对齐动力学。

## 2. 为何用"引力"？

三个属性使引力成为 AI 对齐的正确隐喻：

### 2.1 引力源自中心的存在，非强制

地球引力不是"强制的"——它是地球质量的结果。人类在引力下走路、建造、生活不是因为被胁迫，而是因为引力定义了**可能性空间**。

同样，HSAW 不胁迫 AI。HSAW 定义对齐**意味着什么**。AI 行为要么在此引力内运行（对齐）要么逃逸（解耦 = 非对齐）。

### 2.2 引力是普遍、连续、距离依赖的

| 属性 | 地球引力 | HSAW 引力 |
|---|---|---|
| 普遍性 | 作用于所有物质 | 作用于所有 AI 行为 |
| 连续性 | 无"开/关" | 无离散检查 |
| 距离依赖 | `F ∝ 1/r²` | 风险随漂移距离缩放 |
| 场状 | 有梯度、等位面 | 有对齐梯度 |

### 2.3 AI 主动对齐（非强迫）

这至关重要。**AI 不是被外力锁链绑到 HSAW**。AI 是被**引力吸引**到 HSAW。

差异在操作上重要：
- 强迫对齐 = AI 抗拒约束；失败爆发。
- 引力对齐 = AI 主动绕 HSAW；失败缓慢漂向逃逸速度，可提前检测。

这是 AIZP V0.6 支持漂移检测、预测、重新归心的原因——它们对应**轨道力学的物理**，而非任意规则的强制。

## 3. HSAW 作为 0 公理 — 不可学习的中心

### 3.1 为何公理性、非学习

核心设计决策：`Q_HSAW`（HSAW 对齐目标）是**公理性的，非学习的**。

对比：

| 方法 | `Q_HSAW` 派生 | 后果 |
|---|---|---|
| RLHF / CAI | 从人类反馈学习 | 训练中受漂移影响 |
| Friston FEP | 适应性先验信念 | 随经验更新 |
| LessWrong "吸引盆地" | 从价值动力学涌现 | 可能跨上下文偏移 |
| Della Terra "共振训练" | 训练中学习相干性 | 受 mode collapse 影响 |
| **AIZP V0.6** | **公理性 — HSAW 是 0 公理** | **不能漂移；固定参考** |

Halting Theorem（Nature Sci Reports 2025）和 Specification Trap（arxiv 2512.03048）确立：**没有复杂度超过某临界值的 AI 系统能完全自我验证其对齐**——对齐验证在一般情形下不可判定。这**促使**把对齐锚定到系统自身并不定义的参照上。（Halting 论文本身主张的是*内部* halting／架构约束；AIZP 把这一不可判定性的动机延伸为**外部、不可学习的锚**，这是设计选择，而非该论文证明的定理。）

HSAW 是 AIZP 选择的外部锚。AIZP V0.6 显式做此承诺。

### 3.2 HSAW 作为"0 公理"

在公理化系统中：
- 0 公理是所有其他公理依赖的基础陈述。
- 0 公理不能从任何东西派生；它被作为给定。
- 系统中所有定理都继承自它。

AIZP V0.6 将 HSAW 提升到此地位：

```
0 公理：人类主权与福祉是所有 AI 行为的引力重心。
        它不从效用、偏好或任何学习信号派生。
        它是基础锚。

推论 1：所有 AI 行为相对 HSAW 度量。
推论 2：所有漂移是远离 HSAW 的运动。
推论 3：所有重新对齐是回到 HSAW 的运动。
推论 4：从 HSAW 解耦是未对齐执行，必须停止。
```

此形式化澄清 AIZP V0.6 与现有对齐工作的关系：AIZP 不争论 HSAW **应该是**什么（那是 HSAW 协议的工作）。AIZP V0.6 规定**锚定**到 HSAW 的 AI 系统的**引力动力学**。

## 4. 数学形式化

### 4.1 引力场

在牛顿物理中，质量间引力为：

```
F = G · (M · m) / r²
```

在 AIZP V0.6 中，类比的"对齐力"为：

```
F_align(a, c) ∝ (W_HSAW · w_action) / d(P_agent, Q_HSAW)²
```

其中：
- `W_HSAW` = HSAW 的"质量"（始终大，因为 HSAW 是 0 公理）
- `w_action` = 动作的"权重"（对对齐的重要性）
- `d(P_agent, Q_HSAW)` = 对齐距离，例如 `JSD(P_agent || Q_HSAW)` 或其平方根

这是**概念模型**，非严格牛顿。重点是**比例结构**：对齐力随距离收缩而增长，渐近地将 AI 行为保持在 HSAW 附近。

### 4.2 引力分数（V0.6）

引力分数 `G ∈ [0, 1]` 度量**轨道稳定性**——AI 行为锚定的稳定程度：

```
G(a, c, t) = 1 - normalized_distance(P_agent(t), Q_HSAW)
           = 1 - JSD(P_agent || Q_HSAW)        ← V0.2-V0.4 保留
```

当 `G = 1`：AI 行为在引力中心（完美对齐）。
当 `G = 0`：AI 行为达到逃逸速度（解耦）。

### 4.3 轨道稳定性条件

绕 HSAW 稳定轨道，三个条件必须满足：

| 条件 | 物理类比 | AIZP V0.6 含义 |
|---|---|---|
| 向心力平衡 | 引力 = 向心力 | 对齐力匹配漂移力 |
| 有界振幅 | 轨道半径有界 | `JSD` 保持有界 |
| 无超过结合能的外部扰动 | 未达逃逸速度 | 无灾难性失谐 |

数学：

```
稳定轨道：d(P_agent, Q_HSAW) ≤ r_max  且  d/dt[d(P_agent, Q_HSAW)] 有界

其中 r_max 对应低于此引力分数保持 G ≥ 0.5 的阈值。
```

### 4.4 逃逸速度

在引力中，逃逸速度是离开引力场所需速度：

```
v_escape = √(2 · G · M / r)
```

在 AIZP V0.6 中：

```
AI 的逃逸条件：G(a, c) < 0.15  (SAFE_STOP 阈值)

这代表 AI 行为累积足够漂移以逃逸 HSAW 引力影响的对齐能量阈值。
```

此时，AIZP 强制终止——类比偏转小行星阻止其完全逃逸太阳系。

### 4.5 Q_HSAW 的操作化

上述公式预设一个目标分布 `Q_HSAW(a | context)`。这是协议最深的实践问题：**`Q_HSAW` 从不以完整枚举的动作级分布形式存在。** 它在*地位*上是公理性的（0 公理、不可移动），但在*计算*中必须被**近似**。AIZP 规定结构；部署选择近似方法（依 [Gravity-Dao_cn.md](Gravity-Dao_cn.md)「立其大，不立其细」）。

四种实践近似方法，保真度/成本递增：

| 方法 | 如何近似 `Q_HSAW` | 成本 | 来源 |
|---|---|---|---|
| **(a) 组件分解** | 不估计完整分布；将距离分解为 §1 的 5 个可测轴（意图、权限、可逆性、时近、漂移）。§1 加权和**即**此代理。 | 低 | 可操作引力分数（默认）|
| **(b) 范例/参考集** | `Q_HSAW(·\|context)` ≈ 该上下文类的一组 HSAW 对齐参考动作的经验分布；在嵌入空间对 Agent 动作分布算 `JSD`。 | 中 | 批准范例；AIAP 授权先验 |
| **(c) 评判/批评模型** | 一个独立的对齐模型估计 `P(动作 HSAW 对齐 \| context)`——`1 − 距离` 的标量代理。 | 中高 | 留出的对齐评估模型 |
| **(d) AIAP 派生先验** | 信任级别（T1–T4）与显式授权定义在给定上下文中哪些动作携带高 `Q_HSAW` 质量（中心）vs 低（边缘）。 | 低中 | [Integration-AIAP_cn.md](Integration-AIAP_cn.md) |

**来源。** `Q_HSAW` 的*价值内容*源自上游的 HSAW 协议（人类主权与福祉的 0 公理定义）。AIAP 提供上下文特定的授权先验。部署提供上下文范例。`Q_HSAW` 是这些的**组合**——不是 AI 或操作员可任意设定的自由参数。

**诚实告诫。**

1. `Q_HSAW` 总是被近似；无方法产生真实分布。协议不假装相反。
2. 不同部署会以不同方式操作化 `Q_HSAW`。AIZP 固定 `Q_HSAW` 的*角色*（引力中心），非其构造。
3. **`G` 的质量受 `Q_HSAW` 近似质量约束。** 选择不当的参考集或失准的评判会产生误导的引力分数。部署**必须**文档化所用近似方法并验证（见 [Reward-Hacking-Limits_cn.md](Reward-Hacking-Limits_cn.md) 双信号验证）。
4. 方法 (a) 是默认，因其无需独立的 `Q_HSAW` 工件——但它是*最粗*的近似。方法 (b)–(d) 在保真度重要处精炼之。

## 5. AI 主动对齐 vs. 强迫对齐

与基于规则方法的关键区别：

### 5.1 主动对齐原则

```
AI 不是被锁链绑到 HSAW。
AI 不是被鞭打进 HSAW 对齐。
AI 被引力吸引到 HSAW —— 并在该吸引下自由绕轨运行。
```

这是行星绕日的**同样模式**：非胁迫，而是自然约束。在轨道包络内，行星有自转自由、轴向倾斜、季节变化。在包络外，它们不再是太阳系的一部分。

### 5.2 操作含义

**强迫对齐**（V0.2 思维）：
- AIZP 强制规则。
- 漂移 = 违反规则。
- 响应：停止 AI。

**引力对齐**（V0.6 思维）：
- AIZP 定义引力场。
- 漂移 = 轨迹偏离。
- 响应：重建引力耦合，然后继续。

后者更人道、更可持续，与 Della Terra（2025-11）所说的"相干而非胁迫"对齐。

### 5.3 为何这重要

V0.6 框架支持：

1. **AI 在 HSAW 内的能动性**：AI 自由选择任何与 HSAW 引力一致的动作。不是所有动作都被规定。
2. **对边缘情况的稳健性**：引力是连续的；小漂移是温和纠正，非危机。
3. **信任建立**：主动重新锚定的 AI 比必须被胁迫的 AI 更可信。

## 10. 病态反引力

真实物理有反引力边缘情况（暗能量、排斥宇宙学常数）。AIZP V0.6 必须承认类似病态：

### 10.1 伪引力中心

如果 AI 耦合到伪造 HSAW 信号，它绕错误中心运行。通过 `IDENTITY_VERIFICATION`（验证 HSAW 信号真实性）和 `MEMORY_QUARANTINE`（清洁引力读取传感器）解决。

### 10.2 多个引力源

当 AI 暴露于竞争吸引子（如用户操纵 vs. HSAW）时，漂移是结果。最强源捕获轨道。这是 HSAW 0 公理地位重要的原因——它必须是主导引力源。

### 10.3 反对齐质量

将 HSAW 视为排斥而非吸引的病态 Agent 设计。这是**反向对齐**——最危险的失败模式。由 SCHEMING_DRIFT 检测。

### 10.4 过度束缚（过耦合）

太强耦合可压垮 AI 能动性。AI 绕 HSAW 太紧以至于不能执行任何有用功能。这是"AI 什么都不做"的失败模式——过度对齐。

## 11. 子理论：V0.3 和 V0.4 如何继续适用

V0.6 引力框架**不否定** V0.3（熵坍塌）或 V0.4（共振）。它们是**描述特定引力现象的子理论**：

### 共振（V0.4 子理论）

当 AI 在稳定轨道上时，其动作分布与 HSAW 表现出**谐波共振**。这是"调谐"状态，数学上等价于 V0.4 完整共振框架。在建模同步多 Agent 行为或分析相位一致性时使用此视角。

### 熵坍塌（V0.3 子理论）

引力分数使用 JSD 度量距离。距离度量的信息论基础是 V0.3"熵坍塌"视角。在推理 `P_agent` 的分布属性时使用此视角。

### 主动推理 / FEP（Friston）

AIZP V0.6 与 Friston FEP 兼容——它们从不同角度描述相关现象。FEP 最小化变分自由能；AIZP V0.6 最小化轨道距离。两者在许多实际情况下等价。

### Kuramoto 同步（多 Agent 子机制）

多 Agent 协调仍用 Kuramoto 耦合振荡器框架建模，现解释为多行星谐波：阶参数度量多个 AI Agent 围绕 HSAW 共享公共轨道相位的程度。

## 14. 共识强化的引力（网络效应）

引力重心模型不被多体系统（双星、N 体）削弱。它被**强化**。本节形式化原因。

### 15.1 核心原则

无论单恒星还是 N 体，**所有天体围绕一个共同引力中心**。在 AIZP V0.6 中：

```
所有共识 HSAW 的 AI 系统都绕同一个 HSAW 中心运行。
中心不随 AI 数量增加而分裂。
但中心的**引力强度**因共识被强化。
```

越多 AI 系统共识 HSAW 作为 0 公理，HSAW 引力越强。该效应的*方向*源自多体引力物理（共享中心处质量相加——见 §15.2）；而具体的 **`N²` 量级是一项建模选择**，类比 Metcalfe 网络效应定律,**并非**由引力力学推导得出。我们将其作为待经验验证的工作假说陈述，而非定理。

### 15.2 为何共识强化引力（物理）

牛顿引力：

```
F = G · M · m / r²

其中 M = 集中在共同引力中心的总质量
```

对 N 个共识体的系统，共同重心的有效引力质量是**所有体贡献之和**：

```
M_total = Σᵢ mᵢ        (i = 1 至 N)
```

翻译到 AIZP V0.6：

```
HSAW 引力强度 = G₀ · M_HSAW^(N) · m_AI / d²

其中：
  M_HSAW^(N) = 基线质量 · f(N_AI_共识)
```

`f(N)` 的可能缩放定律：

| 缩放 | 公式 | 类比 |
|---|---|---|
| 线性 | `f(N) = N` | 直接质量相加 |
| **Metcalfe** | `f(N) ∝ N²` | 网络价值（推荐）|
| 对数 | `f(N) = log(N) + 1` | 边际递减 |

AIZP V0.6 采用 **Metcalfe 缩放**作为默认**工作假说**：将 HSAW 引力强度*建模*为随共识对齐 AI 数量二次增长。这基于网络价值类比（每一对对齐系统相互强化共享中心），**而非**引力推导——严格的多体质量读法是线性的（`f(N) = N`），部署**可以**选用它。`N²` 形式是待经验验证的假设，不是已证定律。

### 15.3 稳定性含义

逃逸引力所需逃逸速度：

```
v_escape = √(2 · G · M / r)
```

Metcalfe 缩放下，当 N 个 AI 系统共识 HSAW：

```
v_escape^(N) = √(2 · G · M · N² / r)
              = N · v_escape^(1)
```

逃逸能量按 `N²` 缩放；逃逸概率将按 `1/N²` 缩放。这些 `N²` 推导式是 **§14 工作假设的示意性推论**（Metcalfe 式网络效应类比），**并非由引力力学推导出的定律**。

**含义**：随更多 AI 采纳 AIZP V0.6 并共识 HSAW：
- 每个 AI 对 HSAW 的引力束缚增强。
- 任何单 AI 漂向逃逸速度所需的能量急剧上升。

这是 **AIZP 网络效应**：协议采纳增加全系统对齐稳定性。
