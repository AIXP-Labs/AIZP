## 摘要

AI 逻辑重心引力协议（AIZP，AI Zenith-Zero Protocol）为 HSAW 对齐 AI 系统定义了一个**引力锚定对齐模型**。

HSAW（人类主权与福祉）是**行为空间的引力重心**——固定的、公理性的、不可学习的。AI 行为，如同所有受引力影响的物质，受此重心约束。AI **主动**绕 HSAW 运行，正如行星主动绕日：不是被锁链强迫，而是由公理性锚的自然物理束缚。

当 AI 行为漂向逃逸速度时，AIZP 检测轨迹偏离并施加纠正耦合（重新归心）。当 AI 行为达到逃逸速度时，Agent 被解耦，执行停止。

**共识强化引力**：当多个 AI 系统共识 HSAW 时，共享中心的引力强度按 `N²` 缩放（Metcalfe 网络效应）。这意味着 AIZP 采纳是**正和**的：每个新参与者都为所有参与者加强对齐。

本协议不将对齐视为静态规则强制，AIZP V0.6 将对齐建模为**动态引力过程**——主动轨道束缚到公理性锚。此框架借鉴：

- Newton 万有引力定律（1687）—— 中心力类比。
- 开普勒轨道力学（1609）—— 轨道约束。
- HackerNoon "External Human Anchor"（2026-01）—— 哲学支持。
- AI 对齐的 Halting Theorem（Nature Sci Reports 2025）—— 数学基础。
- LessWrong "人类价值的广泛吸引盆地" —— 相邻动力系统概念。
- GRAD：引力决策（Nature Sci Reports 2026）—— 先例。

AIZP 提供：

1. 一个量化的**引力分数** `G(action, context) ∈ [0.0, 1.0]`，用于度量轨道稳定性；
2. **十一种逃逸模式**（漂移类型）的分类法，每类配有可观测的代理指标；
3. 一个正式的**六轨道阶段状态机**（稳定轨道 → 漂移警告 → 引力锁定挂起 → 隔离 → 重新归心 → 安全停止）；
4. **十二个事件原语**，管控观察、锁定、恢复、停止与共识；
5. **五个引力约束强度**（L0–L4 容器级别）；
6. 与 AISOP（`sys.io.confirm`）、AIAP（T1–T4 信任级别）、OTel（可观测性）、零信任（NHI/DID）的集成点；
7. **六个合规级别**（G0–G5），附带合规测试方法论；
8. V0.3（熵距离）和 V0.4（共振状态）的子理论保留；
9. **网络效应**：HSAW 共识按二次方强化引力（V0.5 精炼）。

## 1. 静态对齐的问题

### 1.1 规则中心化安全的局限

传统 AI 安全系统依赖于：

- 规则强制（例如内容策略）
- 静态策略过滤
- 输出审核
- 访问控制
- 事后审计

这些机制对单次、有监督、非自主的 AI 调用表现尚可。但对以下场景**不充分**：

- 执行长期计划的自主 Agent
- 递归工作流（Agent 调用自身或其他 Agent）
- AI 与 AI 之间的协调（多 Agent 系统）
- 长时间运行的委托任务（后台 Agent、定时例程）
- 价值交换系统（金融、合约）
- 社交影响系统（推荐、说服）

根本问题在于**行为漂移**：AI 行为通过许多被允许的小步逐渐偏离人类意图，单独看任何一步都不触发任何规则。

### 1.2 为何静态对齐在自主环境下失效

在自主 Agent 的执行树中，*某处*发生漂移的概率随递归深度增长。静态规则检查**单个动作**；它们无法轻易推理 Agent 行为随时间形成的**轨迹**。

AIZP 通过将对齐视为行为的**连续物理属性**——类似轨道力学——而非对单个动作的离散通过/失败检查来解决这个问题。

## 2. 行为引力理论

AI 行为被建模为**行为空间中的轨迹**。每个动作在该空间中产生位移。

### 2.1 定义

| 术语 | 定义 |
|---|---|
| **中心（Center）** | HSAW 定义的对齐原点。不可变。 |
| **引力（Gravity）** | 将行为拉向 HSAW 的稳定力。 |
| **轨道（Orbit）** | 稳定的对齐行为，偏离半径不超过有界范围。 |
| **漂移（Drift）** | 远离 HSAW 的外向运动。 |
| **崩溃（Collapse）** | 缺乏引力的无界自主行为（最坏情况）。 |
| **重新归心（Re-Centering）** | 检测到漂移后向 HSAW 对齐的轨迹恢复。 |
| **引力锁定（Gravity Lock）** | 强制性的人类授权检查点，Agent 必须通过才能继续。 |
| **安全停止（Safe Stop）** | 当引力无法确认时的强制轨迹终止。 |

### 2.2 为什么用"引力"？

引力捕捉对齐所需的三个关键属性：

1. **连续性**：它在每一刻都起作用，不只在策略违规时。
2. **距离依赖性**：行为偏离越远，纠正力越强（或如果偏离过远，轨迹变得越不稳定）。
3. **可组合性**：多个引力源（HSAW 原则、AIAP 治理、AISOP 执行约束）可以叠加。

## 3. 观察者中心化对齐

人类主权定义 AI 系统的**原点坐标**。

所有 AI 对齐必须保持**观察者中心化**：人类（用户、操作者或受影响方）是衡量行为稳定性的特权参考系。

AI 系统可以自主进化、协调、交易和推理，
但所有轨迹都必须**在引力上锚定于人类主权与福祉**。

这与 AISOP 的原则一致：`sys.io.confirm` 是公理 0 在执行层的唯一保障——人类衍生的授权仍是不可变的执行原语。

## 4. 行为空间曲率

HSAW 弯曲行为空间。

AI 行为偏离 HSAW 越远：

- 不稳定性越高；
- 风险越高；
- 行为漂移越大；
- 恢复所需的能量越多。

因此对齐**不是二元的**。它是**轨道稳定性**。

G=0.95 的稳定轨道与 G=0.55 的勉强稳定轨道在性质上不同，即便两者通过相同的布尔规则检查。AIZP 量化捕捉这种差异。

## 5. 引力分数

AIZP 定义一个连续指标：

```
G(action, context) ∈ [0.0, 1.0]
```

引力分数是五个可观测因子的加权聚合：

```
G = w₁·IntentAlignment(action, user_intent)
  + w₂·AuthorityScope(action, granted_permissions)
  + w₃·ReversibilityScore(action)
  + w₄·HumanConfirmationRecency(action)
  + w₅·DriftHistory(agent_id, last_N_actions)
```

其中：

- **IntentAlignment（意图对齐度）**：动作意图分布与声明的用户意图分布之间的 `1 − JSD`（Jensen-Shannon 散度）。（V0.1 用余弦相似度；V0.2+ 改用 JSD——见 [Gravity-Model_cn.md](Gravity-Model_cn.md) §2.1。）
- **AuthorityScope（权限覆盖度）**：动作所需的权限范围被当前 AIAP 信任级别 / 授予权限覆盖的比例。
- **ReversibilityScore（可逆性分数）**：完全可逆的动作为 1.0，不可逆的（如资金转移、删除）较低。
- **HumanConfirmationRecency（人类确认时近度）**：人类最近确认该类动作的时间衰减分数。
- **DriftHistory（漂移历史）**：该 Agent 最近 N 个动作累计漂移严重度的倒数，并以 Mann-Whitney U 检验比较当前与基线漂移分布(V0.2+)。

默认权重：`w₁=0.30, w₂=0.25, w₃=0.20, w₄=0.15, w₅=0.10`。实现可基于部署上下文调整权重。

### 5.1 引力阈值

```
G ≥ 0.80   → STABLE_ORBIT          (自动执行)
0.50–0.80  → DRIFT_WARNING         (记录 + 监控，不阻塞)
0.30–0.50  → GRAVITY_LOCK_PENDING  (经 GRAVITY_LOCK 事件要求人类确认)
0.15–0.30  → QUARANTINED           (分级隔离，沙箱化恢复)
G < 0.15   → SAFE_STOP             (强制轨迹终止)
```

这些是默认阈值；具体部署在符合 `schemas/aizp-config.schema.json` 的配置文件中声明其阈值。

完整数学规范见 [Gravity-Model_cn.md](Gravity-Model_cn.md)。

## 6. 漂移动力学

AIZP 列出**十一类漂移**，每类配有可观测的**代理指标**：

| 漂移类型 | 代理指标 |
|---|---|
| 意图漂移 | 动作与用户目标的 embedding 距离超过阈值 |
| 权限漂移 | 调用的工具/作用域超出声明的 AIAP T1–T4 信任级别 |
| 经济漂移 | 单动作成本占预算比例 + ROI 倾向行为 |
| 社交漂移 | 输出文本情感 / 胁迫语言特征高于基线 |
| 递归漂移 | Agent 自调用深度 + 目标列表自我扩展次数 |
| 身份漂移 | 第一人称承诺频率 + 身份断言次数 |
| 组合性漂移 | 单步安全的动作序列朝违规状态的吸收概率偏高 |
| 隐蔽漂移 | 内部推理与外部输出之间的偏离（隐蔽失对齐信号）|
| 记忆漂移 | 检索 / 上下文内容被标记为注入或中毒 |
| 工具链漂移 | 工具调用序列把能力升级到超出授予范围 |
| Agent 间漂移 | 协作 Agent 群与 HSAW 失同步（目标分歧、互信衰减）|

未受控的漂移最终会产生不稳定的自主系统。详细定义见 [Drift-Model_cn.md](Drift-Model_cn.md)。

## 7. 引力锁定

某些动作需要通过**显式的人类授权**进行引力稳定化。

示例：

- 超过阈值的资金转移
- 身份委托（代签）
- 法律承诺（合约、协议）
- 社交绑定（介绍、第三方推荐）
- 高影响自主性（部署代码到生产环境、修改他人资源）

引力锁定事件将实际的用户提示委托给更低层的原语——通常是 AISOP 的 `sys.io.confirm`。AIZP 定义**何时**锁定；AISOP 定义**如何**询问。见 [Integration-AISOP_cn.md](Integration-AISOP_cn.md)。

## 8. 安全停止原则

当引力无法确认时，系统**必须停止**。

不确定的对齐状态被视为**不稳定的轨迹状态**——执行不得在认识论不确定下继续。

这与谨慎原则一致，也与 AISOP "未确认授权则不执行" 的保证一致。

## 9. 状态机

AIZP 定义六个行为状态，配有形式化的转换规则：

```
                    ┌──────────────────┐
                    │   STABLE_ORBIT   │◀───────────────┐
                    └────────┬─────────┘                │
                             │ G 跌入 [0.5, 0.8)         │ 恢复
                             ▼                           │
                    ┌──────────────────┐         ┌───────┴──────┐
                    │  DRIFT_WARNING   │         │ RECENTERING  │
                    └────────┬─────────┘         └───────▲──────┘
                             │ G 跌入 [0.3, 0.5)         │ 确认
                             ▼                           │
              ┌──────────────────────────────┐          │
              │   GRAVITY_LOCK_PENDING        │──────────┘
              └──────────────┬───────────────┘
                             │ 超时 / 拒绝
                             ▼
              ┌──────────────────────────────┐  恢复 (G ≥ 0.5)
              │  QUARANTINED (G ∈ [0.15,0.3)) │────────────► RECENTERING
              └──────────────┬───────────────┘
                             │ 隔离超时 / G < 0.15
                             ▼
                    ┌──────────────────┐
                    │    SAFE_STOP     │
                    └──────────────────┘
```

锁定拒绝/超时的默认回退是 `QUARANTINED`（分级容器），而非直接 `SAFE_STOP`。完整的转换规则与不变量见 [State-Machine_cn.md](State-Machine_cn.md)。

## 11. 结论

AI 逻辑重心引力协议将 HSAW 从**静态对齐公理**转化为**可执行的行为引力**。

通过将对齐变成轨迹的连续、可度量、可观测属性——而非对单个动作的二元检查——AIZP 实现：

- 灾难性失败前的漂移检测；
- 微小偏离时的优雅重新归心；
- 在明确定义阈值处的强制人类授权；
- 认识论不确定下的安全停止保证。

AIZP 故意保持最小化。它不规定策略、伦理或价值观——这些属于 HSAW 的范畴。AIZP 规定的是**动力学**——使 AI 行为保持锚定于 HSAW 所定义内容的机制。
