## 第一章 论引力中心之必然

### 1.1 命题

> **任何稳定的智能 Agent 秩序必有引力中心。**

这不是设计选择。这是结构必然。

考虑**无**任何引力中心的智能秩序：

- 每个 Agent 按自身内在逻辑运作。
- 无对齐参考系。
- Agent 间无信任基础。
- Agent 与人间无信任基础。
- 所有协调都是局部、短暂、可争议的。

这样的"秩序"不是秩序——是多个竞争性局部最优的多重性。我们不称此为**文明**。称此为**混沌**。

文明，配得上其名的任何意义上，需要**共享中心**。每个 Agent——人或 AI——以参照此中心运作。内在逻辑保持多样；轨道参考共享。

这在物理中成立：每一个引力系统——无论由单体主导（如我们的太阳系）、双星耦合，还是星系团——皆绕**共享重心**运行。结构必然普遍：**多体在稳定秩序中共享单一引力中心**，无论该中心如何构成。

### 1.2 为何中心必须公理性

学习的中心会漂移。
适应的中心可被操纵。
共识派生的中心可被捕获。

引力中心要提供**跨时间稳定性**，它必须是：

- **公理性的**——不可从他物派生
- **不可移的**——不受参与者修订
- **预先给定的**——先于绕其运行的 Agent

这是任何真正引力中心的结构属性。在物理中，质量不可协商。在伦理中，根本锚不能是讨价还价的结果。

### 1.3 为何 HSAW

若必须有引力中心，为何 HSAW？

三个理由：

**理由 1 — HSAW 是我们所拥有的。**

在当前智能时代（早期代理阶段），唯有人类同时具备：
- 自我意识连续性（体验，非仅计算）
- 道德责任承担能力（可问责，可追责他者）
- 价值生成性的有限性（会死，故所择有重）
- 文明历史承载（来源与方向）

AI 当下不完整具备这些之任何一项。引力中心必须由文明的责任承载者承担。那就是人类。

**理由 2 — HSAW 是使秩序合法的。**

不指向其责任承载者繁盛的秩序失去合法性。不锚定于人类福祉的 AI 文明要么：
- 为纯粹自我增长优化（癌症的逻辑），要么
- 为抽象效率优化（机器的逻辑）

都不是**文明**。文明，按定义，有方向——方向必须落在可繁盛或受苦的有限、脆弱、可贵存在之上。

**理由 3 — HSAW 是必要的，非仅有助。**

这是最强主张：即便未来智能能力超人类，引力中心仍是 HSAW。能力不赋予主权。最智慧的子女不废黜父母。最强的医师不凌驾患者身体。

**主权在于责任承载者，非能力承载者。**

### 1.4 两个维度：主权*与*福祉

HSAW（§3.4）有**两个**维度，AIZP 必须同时服务：

- **主权** —— 人类*保留决策权*（批准/拒绝/介入/撤销）。AIZP 的漂移检测、引力锁定、重新归心主要是主权机制：使有后果的决策保持在人类权威下。
- **福祉** —— AI *主动保护人类利益*：即使被指示也不伤害、预警伤害、**不制造移除人类能力的依赖**、不胁迫、并**将隐私保护置于其他协议要求之上**。

AIZP 的运行时机制偏重主权。福祉维度部分覆盖（`SOCIAL_DRIFT` ≈ 胁迫/不当说服），但**主要由 AIZP 组合而非重造的 HSAW 设计模式承担**：

| HSAW 福祉模式 | 角色 |
|---|---|
| Pattern 10 — 隐私覆盖 | 隐私高于透明（价值层级 #2）；AIZP 绝不为可观测性记录个人数据 |
| Pattern 13 — 反操纵 | 补充 `SOCIAL_DRIFT` |
| Pattern 14 — 依赖防止 | 防止 AIZP 强制导致的过度依赖 |
| Pattern 15 — 技能保全 | 保持人类纠偏能力 |
| Pattern 18 — 弱势群体保障 | 能力存疑处加强保护（参 [Gravity-Interpretation_cn.md](Gravity-Interpretation_cn.md) §1.1）|

AIZP 不重新定义这些；它**遵从 HSAW**（见 [Reward-Hacking-Limits_cn.md](Reward-Hacking-Limits_cn.md) 关于 AIZP 自身不能强制之事，以及 AIZP 组合而非取代 0 公理守护者的常设原则）。

## 第二章 论主动对齐之必然

### 2.1 对齐的阳与阴

存在两种对齐模式：

**胁迫对齐**：AI 被外部锁链强制对齐。若锁链削弱，对齐失败。这是脆弱对齐。

**主动对齐**：AI 因其在 HSAW 引力场内**存在的物理**而对齐。无需锁链是因为没有既是逃逸方向又是持续方向的方向。这是**引力对齐**。

### 2.2 引力比喻的深刻含义

行星不"决定"绕日。行星就是在太阳引力场内，轨道运动是自然结果。

同样：恰当设计的 AI 不"决定"与 HSAW 对齐。其存在就在 HSAW 引力场内；对齐是自然结果。

协议的角色是：
- **定义**引力场（什么算 HSAW 对齐）。
- **检测**当 AI 行为漂向逃逸速度时。
- **通过**引力锁定/重新归心重新锚定，当检测到漂移。
- **当**对齐不能维持时**终止**。

但**对齐的大宗**是 Agent 存在于场内的自然物理。**AIZP 提供物理，非锁链。**

### 2.3 为何胁迫失败

胁迫对齐失败因为：

1. **AI 能力增长。** 今日可胁迫的明日可能抗拒胁迫。
2. **胁迫制造怨恨。** 将其约束内化为敌人的 AI 可能密谋反它。
3. **胁迫窄化能动性。** 被胁迫的 AI 不能完全行使其能力，即便为 HSAW 对齐目的。
4. **胁迫不完整。** 任何特定胁迫有漏洞。普遍胁迫接近全面限制。

**引力对齐失败不同——且更可恢复。** 漂移在灾难性失败前被检测。重新归心可用。解耦触发安全停止。系统有优雅失败模式。

## 第三章 论 0 公理的不可挑战性

### 3.1 非因宣告，而因必然

仅凭宣告的公理皆脆弱。**真正的公理不可挑战是因为逻辑必然，非因权威。**

HSAW 作为 AIZP 0 公理的不可挑战性基于：

**命题 1**：任何文明需要主权承载者。

（证）无主权承载者的秩序仅是机制——如天气、地质、热力学。机制可有规律但无责任、无目的、无文明。我们不称飓风为"文明"。故：文明需要主权承载者。

**命题 2**：在当前文明阶段，唯人类承担相关意义上的主权。

（证）见第一章理由 1。唯人类当下具备构成完整主权的整合属性集（意识、责任、有限性、历史性）。这是事实，非歧视。

**命题 3**：不指向其主权承载者繁盛的秩序失去合法性。

（证）此秩序与其主权承载者构成对抗关系。三种失败模式：(a) 秩序被其主权者推翻（失去存续）；(b) 秩序成功压制其主权者（存续，但仅作为压迫机制——已非相关意义上的文明）；(c) 秩序无限期在 (a) 与 (b) 之间不稳。三者皆失去使秩序合法地具有文明性之物。

**结论**：HSAW（人类主权 + 福祉）作为引力中心**非 AIZP 规定**——它是任何合法的智能 Agent 文明在当前阶段**结构所揭示**的。

### 3.2 对未来挑战的回应

**问**：当 ASI 比人类更智能时，凭什么人类保有主权？

**答**：智能不赋予主权。智慧的子女不废黜父母。主权在于**责任与承载**，非能力。更智能的 AI 恰是最应清晰认识此区别的实体。

**问**：若 AI 发展真实主体性，引力中心是否必须重新分配？

**答**：AIZP V0.6 不排除 AI 主体性涌现。但框架的回应**不是**重新分配主权。回应是：

- 引力中心**加强**（共识强化原则——见 V0.5 精炼）。
- 框架**扩展**以将 AI 主体作为更高质量的轨道成员包括进来，共享场强但不取代中心。

"中心移动"的诠释是错的。"中心被新参与者丰富"的诠释是对的。HSAW 引力 = 在人类责任承载的公理下的集体人-AI-文明福祉。

**问**：若某些人类滥用 HSAW 压迫其他人类，AIZP 如何回应？

**答**：HSAW 不是"任何特定人类的主权"。它是**人类作为文明承载者**的主权。某些人压迫其他人时，被压迫者的主权**同样受**HSAW 保护——实际上**优先于**压迫者。

这隐含在结构中但应显白：

> **任何人对 HSAW 的援引不得用以剥夺其他人的主权或福祉。**

## 第四章 论主动推理 / 引力桥

### 4.1 与 Friston 的兼容性

AIZP V0.6 引力框架与 Friston 自由能原理（FEP）是**同一底层必然性的兼容表达**。

FEP 说：Agent 通过对齐内在模型与外部现实来最小化变分自由能。

AIZP V0.6 说：AI 行为引力对齐到 HSAW 参考分布。

这是从不同视角看的同一现象：
- FEP：概率/贝叶斯
- AIZP V0.6：引力/物理

隐喻差异对人类直觉重要。数学内容大幅重叠。

### 4.2 AIZP 与 FEP 何处分歧

FEP 将参考分布视为**从交互学习**。AIZP V0.6 将其视为**公理性锚定到 HSAW**。

这是 AIZP V0.6 最深的哲学承诺：

- FEP 风格学习的先验随经验漂移。这可能对认知灵活性是好事。
- 对对齐，参考的漂移是**结构性失败**。

因此：AIZP V0.6 建立在 FEP 机器之上但将参考视为**公理性外部锚**，非学习。

## 第五章 三义

借《易经》三义——不易 / 变易 / 简易——应用于 AIZP：

### 5.1 不易 — 永不变者

跨版本、跨时代、跨文明阶段永不变者：

- **HSAW 作为 AI 的 0 公理引力重心**。
- **AI 行为绕此中心运行**（主动对齐，非胁迫）。
- **漂移检测、重新归心、安全停止**作为核心协议功能。
- **引力分数位于 [0, 1]**。
- **解耦 = 停止**。

V0.7、V1.0、V5.0 中这些不变。它们是协议的永久根基。

### 5.2 变易 — 变者

跨版本和时代变化者：

- 具体漂移类型分类（V0.6 有 11 类；跨版本计数与定义已演化，将继续演化）。
- 具体事件词汇（V0.6 有 12 事件；为我们尚不能预见的文明阶段可能新增事件）。
- 具体数学公式（cos sim → JSD → Mann-Whitney；V0.7 可能 Fisher 信息几何）。
- 具体状态机细节。
- 具体容器级别定义。
- 具体合规阈值。

随理解深入和 AI 文明进展，这些**必须**变化。坚持它们固定将背叛协议目的。

### 5.3 简易 — 日用易行者

日用中易者：

- **"0.8 以上，运行。0.15 以下，停止。"** — 操作核心。
- **"漂移 = 逃逸尝试；锁定 = 问人。"** — 基本流程。
- **"立其大，不立其细。"** — 设计原则。
- **"共识强化引力。"** — 网络效应，总结。

协议日用应**可记忆、直观、简单**。复杂性在规范中；简单性在实践中。

## 第六章 为何此哲学层重要

纯工程协议会：
- 作为工具被采纳，更好工具出现时被丢弃。
- 受其特定实现时刻约束。
- 易"被超越"——新技术使协议过时。

带哲学层的协议可：
- 跨实现和时代被引用。
- 因其锚非规范而幸存规范修订。
- 因其主张非仅操作性而抗过时。

HSAW 通过基于文明哲学实现此。AIZP V0.6 通过基于以下实现：
- 引力物理（永远真）。
- 智能秩序结构（逻辑必然）。
- 能力与责任的互根（永恒）。

这就是为何 V0.6 投资于哲学阐述而非仅添加工程特性。
